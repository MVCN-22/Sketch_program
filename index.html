    Publishing on GitHub Pages

    The chart reads its people from a file called org-data.json that sits next to index.html in your repository. Edits you make here stay in your own browser until you upload that file.

    1. Make your changes

      Click Edit, then click people to edit them or use + to add a direct report. You can also import the whole organisation from Excel (⋯ → Import from Excel).

    2. Export the data

      Choose Export org-data.json. The file downloads to your computer.

    3. Upload it to GitHub

      In your repository, click Add file → Upload files, drop in org-data.json (replacing the old one) and click Commit changes.

    4. Done

      Everyone sees the new chart within a few minutes. Reload the page to check.

    First-time setup: create a repository, upload index.html, then open Settings → Pages, choose Deploy from a branch, pick main and / (root), and save. GitHub shows the address of your site at the top of that page.

    Tip: open a person and click Copy link to send someone a link that goes straight to them.
